Text2SQL Agent

Solo build

An LLM-powered app that turns plain-English questions into SQL. Uses a RAG pipeline over a semantic data dictionary to retrieve only the relevant tables, curated few-shot examples to shape query style, and a human-in-the-loop guard that blocks destructive SQL until a user confirms.

  • FastAPI

TTC Subway Delay Forecasting

Team capstone · 6 members

Analyzed 69,000+ real transit delay records to predict delay severity and duration. I owned the regression pipeline — tuning an XGBoost model on log-transformed delay times and using SHAP to explain which operational factors drive long delays.
